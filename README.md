# AURELIS — Private Aviation

架空のプライベート航空ブランドのコンセプトサイトです。予約や問い合わせは送信されません。

## 表示

`index.html` をブラウザで開くか、次のコマンドでローカル表示できます。

```sh
python3 -m http.server 4173
```

GitHub Pages: Settings → Pages → Deploy from a branch → main / (root)。
